# KTHAIS Code Review

Standards for reviewing code in the KTHAIS organization.

## When to use

Apply this skill when reviewing PRs, diffs, or drafting review comments for KTHAIS repos.

## Guidelines

<!-- Replace with organization-specific review criteria. -->

- Check correctness and edge cases before style nits.
- Prefer actionable, specific comments with suggested fixes when practical.
- Call out security, secrets, and destructive operations.
- Match the repository's existing patterns and documented conventions.
- Keep feedback proportional to the change size and risk.
